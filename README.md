# Revision Flow — free, installable revision app (v0.1)

A personal GCSE revision planner that runs as a Progressive Web App on Windows and iPhone.

## What works today

- Add/edit/delete revision sessions, see your week and daily goal, start focus sessions and mark them complete.
- Create topics, rate recall after a review, and get automatically scheduled recall dates.
- See completed revision time by day and subject.
- Each new visitor starts with a blank timetable and chooses their own subjects. Sessions and progress stay in their browser, separate from other visitors. Existing browsers retain their previously saved work and published timetable.
- Export a whole timetable to a standard `.ics` file to import into Apple Calendar or Google Calendar, or add individual events through a Google Calendar link / Apple Calendar `.ics` file.
- Save data in this device's browser, and export/import JSON backups.
- Apply an update generated by ChatGPT using **ChatGPT bridge** (`{"ops":[...]}` JSON). This changes app *data*, not the website's code.
- In-app repeating reminders while the app is actively running, with snooze, dismiss, and quiet hours. Desktop browser notifications are best-effort, based on browser permission and restrictions.
- Offline access after a successful visit to the hosted app.

**Calendar note:** Exports and Google links create calendar copies, not ongoing sync. Importing the same `.ics` twice may duplicate entries. Flexible sessions appear as all-day reminders. Google Calendar: Settings → Import & export → select the downloaded `.ics` file. Apple Calendar: open the downloaded `.ics` file in Calendar.

**Privacy note:** The published timetable file remains visible in the public repository for compatibility with already saved plans. Never place personal backups in GitHub Pages.

## What does not work yet

- **Automatic cross-device sync**: data is local to each device, so your PC and phone do NOT yet sync.
- **Direct write from a ChatGPT conversation**: paste ChatGPT-generated JSON into ChatGPT bridge for now.
- **Background phone push** when the website is completely closed: would need a push-sending server, subscription management and hosted HTTPS setup. iOS does not permit an unignorable alert.
- AI tutoring inside the website: start a session to open ChatGPT instead.

## Run on your computer immediately

Open `index.html` in Chrome or Edge. You can test all regular planner functions. Some browser features (service workers and notifications) need HTTPS or localhost.

To run locally as a real PWA: in this directory, run `python -m http.server 8000`, then visit `http://localhost:8000` in Chrome or Edge.

## Put it on PC and iPhone for £0 extra

One possible free option is GitHub Pages, subject to GitHub's terms and quotas:

1. Create a GitHub account if needed and a new **public** repository, e.g. `revision-flow`. Never upload your exported backups or personal revision data to the repository.
2. Upload the content of this directory to the repository root, preserving `icons/` and the filenames.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`, and save.
4. Use the published HTTPS URL (typically `https://YOUR-USERNAME.github.io/revision-flow/`).
5. On Windows: open the site in Chrome or Edge, then use the browser's **Install app** option.
6. On iPhone: open the HTTPS site in Safari, tap Share and **Add to Home Screen**.

**Privacy note:** GitHub Pages publishes the website *code* publicly, but your revision data remains local to your browser. Never publish private backups in the repo.

## How to use the ChatGPT bridge

Open **ChatGPT bridge** in the app, click **Copy AI instructions**, paste that into a ChatGPT conversation, and describe the revision changes you want. ChatGPT should return a JSON object in a code block. Copy that object into the app's bridge text area and click **Apply changes**.

Supported operations: `add_subject`, `add_topic`, `update_topic`, `add_session`, and `complete_session` by id. Operations are validated together and either all apply or none apply.

Example:

```json
{"ops":[{"type":"add_topic","subject":"Spanish","name":"Imperfect subjunctive","confidence":2},{"type":"add_session","subject":"Spanish","topic":"Imperfect subjunctive","date":"2026-11-19","time":"17:00","duration":45}]}
```

## Next upgrade — private cloud sync

To make ChatGPT edits automatically appear on both devices, connect a private Google Sheet to this app using a proper authenticated method (e.g. Google's browser OAuth and the Sheets API, with the spreadsheet accessible to the signed-in account). This would require a Google Cloud OAuth client and safe deployment configuration. Do **not** publish a sheet with editing permission or hard-code service-account keys/tokens in the website.

Background push would be a separate phase; an HTTPS service worker + subscription API + scheduled push sender could be hosted on a free-tier serverless platform, subject to quota and availability. Persistent alert behaviour is still controlled by the operating system, and must provide snooze/quiet controls.
